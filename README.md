# 🌐 Suraj Reddy — Developer Portfolio

This repository contains the source code for my personal portfolio website — a clean, responsive, developer-focused site built to showcase my experience, technical skills, and featured engineering projects. It is built with Next.js 14, TypeScript, and Tailwind CSS, with a focus on simplicity, accessibility, and performance.

🚀 **Live Site:** https://suraj-portfolio-flame.vercel.app  
📫 **Email:** surajreddy.alluri@gmail.com  
🔗 **LinkedIn:** https://www.linkedin.com/in/mrsurajreddy  
---

## 🧰 Tech Stack

**Framework:** Next.js 14 (App Router)  
**Language:** TypeScript  
**Styling:** Tailwind CSS  
**Animations:** Framer Motion  
**Deployment:** Vercel  
**Icons:** Lucide  
**UI Components:** Custom Components + Radix UI where needed  
---

## 📁 Project Structure
/public          → Static assets (profile photo, resume PDF)
/src
/components    → UI components (navbar, hero, cards, carousel, etc.)
/data          → Portfolio data (projects, experience, skills, about)
/app             → Next.js routes and pages
---

## ⚡ Running Locally
```
npm install
npm run dev
```
Runs at:
http://localhost:3000

## 🚀 Deployment

This portfolio is deployed on **Vercel**.  
Every push to the `main` branch automatically triggers a production redeploy.

## ✨ Features

### • Responsive Hero Section
A clean introduction with headline, subheadline, quick tech stack chips, and social buttons.

### • Featured Projects Carousel
Scrollable, responsive project cards with:
- Problem → Solution → Impact breakdown  
- Tech stack bubbles  
- GitHub links  
- Smooth arrows + dot indicators  
- Auto-resizes for mobile, tablet, desktop  

### • Experience Timeline
High-quality, recruiter-friendly description of roles, impact, and results.

### • Skills Overview
Organized skill groups across backend, cloud, frontend, distributed systems, tools, and databases.

### • Smooth Animations
Section-level reveal animations using Framer Motion.

### • Fully Responsive Layout
Works across:
- Desktop  
- iPad / tablet  
- Mobile
