# 🌐 Suraj Reddy — Developer Portfolio

This repository contains the source code for my personal portfolio website — a clean, responsive, developer-focused site built to showcase my experience, technical skills, and featured engineering projects.  

The site is built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**, designed with a focus on simplicity, accessibility, and performance. It highlights my work as a **Backend / Full-Stack Software Engineer** specializing in **Java, Spring Boot, Microservices, and Cloud Systems**.

🚀 **Live Site:** https://suraj-portfolio-flame.vercel.app  
📫 **Contact:** surajreddy.alluri@gmail.com  
🔗 **LinkedIn:** https://www.linkedin.com/in/mrsurajreddy

## 📌 Features

### 🎯 Professional Overview  
A structured introduction summarizing my background, areas of expertise, and availability.

### 🛠️ Skills Section  
Categorized technical skills covering backend, cloud, frontend, databases, dev tools, and distributed systems.

### ⭐ Featured Projects Carousel  
A responsive horizontal project showcase with:
- Problem → Solution → Impact storytelling  
- Tech stack tags  
- GitHub project links  
- Scrollable cards with arrows + dot indicators  
- Fully responsive layout across mobile, tablet, and desktop

### 💼 Experience Section  
Detailed breakdown of roles, responsibilities, and high-impact contributions.

### 📱 Fully Responsive  
Works seamlessly across:
- Desktop (3-column project cards)
- Tablet (2 cards)
- Mobile (1 card with smooth scroll)

### ⚡ Smooth Animations  
Subtle section reveal animations using Framer Motion.

### 🔍 SEO & Performance  
Optimized Next.js setup powered by Vercel’s edge network.

---

## 🧰 Tech Stack

- **Framework:** Next.js 14 (App Router)  
- **Language:** TypeScript  
- **Styling:** Tailwind CSS  
- **Deployment:** Vercel  
- **Animations:** Framer Motion  
- **UI Components:** Custom components + Radix UI  
- **Icons:** Lucide  

---

## 📁 Project Structure
/public           → Static assets (profile photo, resume PDF)
/src
/components     → Reusable UI components (navbar, hero, cards, carousel, reveal animations)
/data             → Portfolio data (experience, projects, skills, about)
/app              → Next.js routes and page structure

## ⚡ Local Development

```bash
npm install
npm run dev
```

Project will run at:
http://localhost:3000

## 🚀 Deployment

This portfolio is deployed on Vercel, with automatic builds triggered on every push to the main branch.

To trigger a manual production deployment:
vercel --prod
